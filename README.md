# Uttakaladeba Garnaik — Developer Portfolio 🚀

Welcome to the official developer portfolio of **Uttakaladeba Garnaik**, B.Tech Computer Science Engineering student at Nalanda Institute of Technology, Bhubaneswar.

A futuristic, cyberpunk-glassmorphic portfolio engineered for speed, aesthetics, high interactivity, and rich animations.

---

## ✨ Upgraded Features & Innovations

- 🤖 **Embedded UG-AI Knowledge Assistant**: Floating intelligent cyber agent that knows EVERYTHING about Uttakaladeba's profile, career focus in Data Analytics, projects (EMPAIR, Landsafe-NER, JARVIS), SIH 2026 hackathons, and contact details with instant natural language conversational responses.
- 🌐 **Interactive Cyber Constellation Canvas**: Real-time particle physics background reacting dynamically to mouse movement and proximity connections.
- 🎯 **Custom Neon Cyber Cursor**: Smooth-trailing ring with magnetic target snapping and dynamic expansion on links and cards (auto-disabled on touch devices).
- ⚡ **Web Audio API Sound Synthesizer**: Native zero-asset futuristic audio feedback (hover blips, click chimes, success fanfares) with persistent mute/unmute control.
- ⌨️ **Dynamic Hero Role Typewriter**: Cycles through developer titles (`B.Tech CSE Student`, `Full-Stack Web Craftsman`, `SIH Finalist`, `AI Builder`).
- 💎 **3D Card Perspective Tilt & Dynamic Specular Glare**: Physics-based 3D tilt with real-time specular light sheen reflecting mouse coordinates across cards.
- 🕒 **Live System HUD**: Digital clocks ticking live in IST and UTC with real-time telemetry status.
- 🔍 **Interactive Category Filters & Quick-View Modals**: Filterable project showcases and skill inventories with instantaneous preview modals.
- 🏆 **SIH Hackathon Showcase & Stats Counters**: Smooth cubic-eased numbers animating up upon scroll viewport entrance.
- 📚 **Integrated "Learn With Me" Portal**: Unified course and video lecture cards with direct YouTube stream links and downloadable Drive notes.
- ✉️ **AJAX Contact Form with Confetti Cannon**: Asynchronous Web3Forms delivery with high-tech loading state, instant toast notifications, and confetti burst.
- 📱 **Responsive Mobile Drawer**: Glassmorphism mobile menu drawer with animated hamburger-to-cross transformation.
- 🚀 **Extreme Payload Optimization**: Extracted embedded base64 assets to compressed image files, dropping `projects.html` from 3.7 MB to 16 KB (99.6% speedup!).
